# Example: a quick analysis of Acme Notes

Acme Notes is a fictional desktop app for private notes. Its repository is generated by [`make_acme.py`](example/make_acme.py), with problems planted on purpose, so you can see what the scripts find and what the skill turns their output into. The numbers below are what the scripts printed on 4 October 2026, and on 5 October for the two business model rows. The analysis at the end follows the format the skill asks for. It was written from these outputs, and it leaves out the side-by-side with your own product that a real run includes.

## Try it in a minute

No network and no accounts are needed. From the repository root:

```bash
python3 docs/example/make_acme.py /tmp/acme --raw /tmp/acme-raw
python3 skills/weigh-in/scripts/git_stats.py /tmp/acme
python3 skills/weigh-in/scripts/license_scan.py /tmp/acme
python3 skills/weigh-in/scripts/telemetry_scan.py /tmp/acme
python3 skills/weigh-in/scripts/app_security_scan.py /tmp/acme
python3 skills/weigh-in/scripts/github_traction.py acme/acme-notes --offline /tmp/acme-raw --no-search --check-interval-hours 4
python3 skills/weigh-in/scripts/monetization_scan.py code /tmp/acme
python3 skills/weigh-in/scripts/monetization_scan.py page /tmp/acme-raw/pricing.html
```

Each script prints JSON. `--raw` saves fictional GitHub API responses, so the traction script can run offline, and a fictional pricing page.

## The document the skill asks for

What follows is the quick variant: one document, every fact with its source, reasoning marked.

---

### Acme Notes: quick analysis

**Date.** 4 October 2026. **For.** The founders and the product team.
**Basis.** `acme/acme-notes` at `c739bf75` (10 August 2026); GitHub API responses saved on 4 October 2026.
**Method.** Read only: nothing installed or run, no account created. **Re-checked at the source:** the analytics code path, the three license files, the update interval.
"(inference)" marks reasoning.

#### 0. In short

1. **Acme Notes is one person's project with two helpers.** Dana Reyes wrote 8 of 13 commits under two emails; the bus factor is 1 (`git_stats.py`).
2. **About 318 copies run at any moment** (estimate: update checks every four hours, `electron/main.js:13`, about 1,909 checks a day). New installs fell from 72 a day after v0.1.0 to 19 a day after v0.2.0.
3. **The privacy promise does not match the code.** The README says "No tracking, ever"; PostHog starts with an `identify` call and no consent step (`src/analytics.ts:4-5`), and telemetry is on by default (`src/settings.ts:1`). Verified.
4. **An open core in three licenses:** an MIT core, relicensed from Apache-2.0 a week after a CLA arrived; an AGPL sync server; an enterprise folder that needs a license key.
5. **Hardening gaps:** context isolation off, no fuses, library validation disabled, and a sync server bound to every network interface (signals; not yet confirmed as exploitable).
6. **What we may take:** ideas and code from the MIT core with its notices; nothing from `ee/`; the sync server only under the AGPL.

#### 1. Who they are and what they sell

Acme Labs ships a free MIT app and earns from three things on its pricing page (`pricing.html`, saved with the example): Pro at $8 a month billed yearly, with unlimited devices and encrypted sync; Team at $12 per user a month; and an enterprise edition on a call. The free tier caps devices at three. The enterprise edition is the `ee/` folder, switched on by a key (`ee/licensing.ts:1`); no billing code is in the repository, so payments run elsewhere (inference). A full analysis compares this with your own model, row by row, in document 08.

#### 2. License and reuse

| What we want | Where | License | Answer |
|---|---|---|---|
| Learn from or copy the note editor | `src/` | MIT | Yes, keeping the copyright and license notice |
| Reuse the sync server | `sync-server/` | AGPL-3.0 | Only if our version and any network service built on it go under the AGPL |
| Anything in `ee/` | `ee/` | Custom, all rights reserved | No |

The CLA lets Acme Labs relicense contributions (`CONTRIBUTING.md`). A move of the core to a source-available license is possible (inference); depend on it accordingly.

#### What not to say

- "Acme tracks you" or "Acme is insecure": judgments. Say what the code does, with the date and the file.
- "Hundreds of thousands of downloads": 97% are update checks.
- Any user count: the repository shows running copies, not people.
